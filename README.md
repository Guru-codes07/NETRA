## 📌 About

This repository contains the work for our **Smart India Hackathon (SIH) 2026** project:

**AI-Powered Criminal Network Analysis System**

The project focuses on building an **AI-assisted criminal network intelligence platform** that can help authorized investigators discover hidden relationships across fragmented and heterogeneous datasets.

The system aims to transform disconnected investigation data into an **interactive relationship graph**, allowing investigators to identify potentially significant connections, communities, anomalies, and patterns.

> **Fragmented Data → Unified Intelligence Graph → Hidden Relationships → Explainable Insights**

---

## 🎯 Problem

Criminal investigations can involve large amounts of information distributed across different sources, such as:

- FIR and case records
- Call/communication records
- Financial transactions
- Phone numbers
- Locations
- Vehicles
- Criminal histories

When these sources remain isolated, discovering relationships between entities becomes difficult and time-consuming.
